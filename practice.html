第 1 關　骨架有提示詞

這關要達成什麼

做出單一 HTML 檔，含七個分頁（總覽／學生名單／課程規劃表／教室日誌／學生回饋單／經費核銷／備份與設定），並把三條硬規矩（單一檔案、零外部資源、資料只存自己電腦）講清楚。

可複製提示詞

這是第一步，請在我現在打開的這個資料夾根目錄，新建一個檔案：
仰望科學社團管理系統_我的學校.html
（之後每一步都改這同一個檔案，不要另外開新檔。）

請幫我做一個「仰望科學社團管理系統」，給參加「財團法人仰望教育基金會・國中小科學社團扶助計畫」的老師使用。

【三條硬規矩，從這一關到最後一關都要遵守】
1. 單一 HTML 檔：HTML、CSS、JavaScript 全部寫在同一個檔案裡，不可以拆成多個檔案。
2. 零外部資源：不准連任何外部網址。不准用 CDN、不准載入外部字型、外部圖片、外部 JS、任何框架或套件（不要 React、不要 Vue、不要 jQuery、不要 Bootstrap、不要 Tailwind、不要 Google Fonts、不要 Font Awesome）。整個檔案裡不可以出現任何 http 或 https 開頭的 script、link、img。老師要能雙擊打開、完全沒有網路也能用。
3. 全部介面用繁體中文、台灣用語（軟體不是軟件、資料不是數據、預設不是默認、螢幕不是屏幕）。使用者是不太會電腦的國中小老師，用詞要白話。
4. 資料只存在老師自己的電腦，不可以送到任何伺服器、不可以呼叫任何 API。

【這一關只要做骨架，功能之後幾關再加】
(1) 最上面固定一條頂欄：深色底、白字，左邊寫系統名稱與「財團法人仰望教育基金會 × 國立東華大學」，右邊放三個統計方塊（社團學生人數、累計出席率、已上課週數）與「已自動存檔 時:分:秒」。現在數字先顯示「–」沒關係。
(2) 頂欄下面一排分頁按鈕，共七個，順序固定不可以改：
    總覽｜學生名單｜課程規劃表｜教室日誌｜學生回饋單｜經費核銷｜備份與設定
    點哪一個就顯示哪一頁，是同一個檔案內切換顯示，不是換頁、不是換檔案。
(3) 每一頁先放一個標題與一句話說明，內容之後再補。
(4) 視覺風格：淺米白底 #faf7f0、白色卡片、3px 純黑外框、右下 6px 純黑硬陰影（不要模糊陰影），按鈕按下去往右下沉進陰影裡。內文 17px，因為讀者裡有老花眼的老師。表格用白底細線，不要跟按鈕一樣厚框。
(5) 手機寬度 390px 時整頁不可以橫向捲動，表格請自己在容器內橫捲。

【做完請自己驗收並回報】
・檔案完整路徑與大小。
・雙擊可以打開，七個分頁都點得動、切得過去。
・用瀏覽器的檢視原始碼搜尋 http，確認沒有任何載入外部資源的 script／link／img。

做完你應該看到

  • 資料夾裡出現一個 .html 檔，點兩下用 Edge 或 Chrome 打得開。
  • 上面一排七個頁籤，每個都點得動、切得過去。
  • 把網路關掉重新整理，畫面一樣正常。

常見的錯：AI 會自作主張用 CDN 載入 React、Bootstrap 或 Google 字型——關掉網路就變成一片白。要明講「不准連任何外部網址」，發現了就叫它「把所有外部載入拿掉，改成純 HTML/CSS/JavaScript 寫在同一個檔案裡」。

第 2 關　記得住有提示詞

這關要達成什麼

做三層儲存：localStorage 自動存檔、HTML 內嵌 #bootState 節點（讓資料跟著檔案走）、匯出／匯入 .json。

可複製提示詞

延續上一步做好的同一個檔案，不要重做、不要換檔名、不要新開一個檔，只在原檔上繼續加功能。已經做好的功能不可以弄壞。

這一關做「資料記得住」。請做三層儲存，三層都要有，缺一不可。

【第一層：localStorage】
用瀏覽器 localStorage 存全部表單資料，鍵值用一個固定字串常數（例如 var STORE_KEY = "yw-club-mgr-v1"）。任何欄位一改就自動存檔，並更新頂欄的「已自動存檔 時:分:秒」。

【第二層：HTML 內嵌資料節點（這是最容易被漏掉、也最重要的一層）】
在 HTML 裡放一個節點：
<script type="application/json" id="bootState">null</script>
每次自動存檔時，把整包資料的 JSON 也寫進這個節點的內容（記得把 < 換成 \u003c，避免把 HTML 弄壞）。

【第三層：匯出／匯入 .json】
在「備份與設定」分頁做兩顆按鈕：
・「匯出備份（.json）」：把全部資料存成一個 json 檔（用 Blob 下載），檔名含校名與日期。
・「匯入備份」：用 FileReader 讀檔、JSON.parse 還原。匯入前先自動下載一份「匯入前自動備份.json」；先補齊欄位、畫面渲染成功才真正落地，失敗就原資料完全不動並告訴使用者「匯入已取消」。
另外再做「清除全部資料」（要兩次確認）。

【開檔還原的順序（請完全照做）】
先讀 localStorage；**只有在 localStorage 這個位置沒有資料時**，才去讀 #bootState 的內容還原，並立刻把它存進 localStorage。
→ 已經在用的資料永遠優先，不會被舊快照蓋掉；按「清除全部資料」後重新整理也不可以還魂。

【一個一定要避開的坑】
不要用 DOM 元素的屬性（例如 dataset、自訂 attribute）當「已初始化／已載入」的旗標。因為 Ctrl+S 存下來的快照會把屬性一起存走，重開後判斷會失準。請用 JavaScript 變數當旗標。

【為什麼要這樣做】
老師會把檔案存到隨身碟、帶去別台電腦。localStorage 不會跟著檔案走，內嵌節點會。這是這個系統能「帶著走」的關鍵。

【做完請自己驗收並回報】
1. 隨便輸入一些資料 → 關掉分頁 → 重開 → 資料還在。
2. 按 Ctrl+S，存檔類型選「網頁，完整」，把存出來的檔案移到別的資料夾再打開 → 資料還在。
3. 按「清除全部資料」→ 重新整理 → 資料是空的，不會自己跑回來。
4. 匯出 .json 再匯入，資料一樣。

做完你應該看到

  • 隨便打幾個字 → 關掉分頁 → 重開 → 資料還在。
  • 按 Ctrl+S（存檔類型選「網頁，完整」）存出來的檔，搬到別的資料夾、換一台電腦打開，資料也還在。
  • 按「清除全部資料」→ 重新整理 → 是空的，資料不會自己跑回來。

常見的錯：AI 拿 DOM 屬性（dataset）當「已初始化」旗標，Ctrl+S 之後屬性被一起存走，重開就壞掉。要叫它改用 JavaScript 變數。另一個常見錯是只做了 localStorage，漏了 #bootState——那樣檔案帶到別台電腦就變空的。

第 3 關　名單有提示詞

這關要達成什麼

做「學生名單」分頁：從 Excel 貼上整批匯入、可編修、可匯出 CSV。

可複製提示詞

延續上一步做好的同一個檔案，不要重做、不要換檔名、不要新開一個檔，只在原檔上繼續加功能。已經做好的功能不可以弄壞。

這一關做「學生名單」分頁。

(1) 一個大的貼上框，老師從 Excel 整批複製學生貼進來，按「貼上匯入」就進系統。
    解析規則（很重要，請完全照做）：
    ・一行一位學生。
    ・先用 Tab、半形逗號、全形逗號、頓號切；切完只有一段時，才改用空白切（空白包含全形空白）。
    ・第一個非空白列如果含有「座號／學號／編號／班級／姓名／名字／備註」這些字，就當成 Excel 的標題列整列略過，並在訊息裡明講「第 1 列看起來像標題列，已略過」。
    ・用空白切的那條路：開頭是純數字就當座號；接著若某一段以「班」結尾就當班級；**剩下的全部併回姓名**。例如「01 Yosi Takun」要變成 座號 01、姓名「Yosi Takun」，絕對不可以把 Yosi 當成班級。
    ・支援三種格式：「座號 班級 姓名」「班級 姓名」「姓名」。
    ・重複的（同班級同姓名）跳過，訊息要說略過幾位。
    ・匯入完成的訊息要寫明「匯入 N 位」。
(2) 名單表格：座號、班級、姓名、備註都可以直接在格子裡改，每一列有刪除鈕，改完即時存檔。
(3) 三顆按鈕：「＋手動加一位」「列印學生名單（附件一）」「匯出名單 CSV」。
    匯出 CSV 要加 UTF-8 BOM，Excel 打開才不會亂碼。
(4) 頁面上提醒老師：Excel 會把座號「01」變成 1，所以附件一建議用「列印學生名單」出紙本。

3. 同一批再貼一次 → 訊息說略過 15 位重複。

第 4 關　核心計算有提示詞

這關要達成什麼

做「課程規劃表」與「教室日誌」：點名三態、出席率、材料費份數。這是老師核銷會被主計室看的數字，算錯要重來。

可複製提示詞

延續上一步做好的同一個檔案，不要重做、不要換檔名、不要新開一個檔，只在原檔上繼續加功能。已經做好的功能不可以弄壞。

這一關做「課程規劃表」與「教室日誌」，這是整個系統的計算核心，數字算錯老師核銷會被退件，請特別小心。

【課程規劃表】
表格欄位：週次｜日期｜課程內容｜時數｜任課教師｜備註。列數等於「總覽」設定的總週數（預設 24，可改 1～60）。時數預設 2，可以改，允許 0.5 的倍數。所有格子直接編輯、即時存檔。
按鈕：「列印課程規劃表」「列印授課時數表（鐘點費核銷用）」「匯出 CSV」。
授課時數表只列有日期或有點名的週次，每列顯示該週實填時數，頁尾合計要用加總，**不可以寫死 2**。

【教室日誌】
(1) 上方：週次下拉（1～總週數）、該週日期與主題（自動從課程規劃表帶過來）、「全到」按鈕、「清除本週」按鈕。
(2) **進到某一週時，全部學生預設「出席」**，老師只要把沒來的改掉。每位學生一顆按鈕，點一下循環切換：出席 → 缺席 → 請假 → 出席。
(3) 點名表上方的摘要列要顯示：
    「本週出席 N 人／共 M 人（缺席 x、請假 y）　→　加上授課教師 T 位＝材料費 (N+T) 份」
    ・T ＝ 總覽基本資料裡**實際填了幾位**指導老師（填 1 位就算 1、填 2 位就算 2）。兩位都沒填時暫以 2 位計，並在摘要下方用紅字提醒「請先到總覽基本資料填指導老師姓名」。
    ・如果還有人沒被點到（部分點名），摘要要多一行紅字：「還有 N 位未點名，這週的數字先不算數」。
(4) 出席率算法（這一條最常算錯）：
    出席率 ＝ 出席人數 ÷ **總報名人數**。請假與缺席**都要算進分母**。
    只累計「有點名過」的週次。
(5) 材料費份數 ＝ 當週出席學生數 ＋ 實際授課教師人數。核算公式是（上課人數＋實際授課教師人數）× 主題 × 250 元，請把這句話寫在畫面上。
(6) 同一頁下方再做一塊「本週課程紀錄（成果報告書・參 的素材）」：一個多行文字框（文字說明）＋照片檔名欄＋圖說欄，逐週各自儲存。加一顆「列印課程紀錄（參）」按鈕，把有填的週次整理成一張表印出來。

【做完請自己驗收並回報】
1. 進第 1 週 → 全部預設出席。
2. 把 2 個人改成請假 → 材料費份數與出席率兩個數字**同步跟著變**，而且請假的人仍然算在出席率的分母裡。
3. 15 人只點 10 人 → 出現「還有 5 位未點名，這週的數字先不算數」。
4. 總週數改成 28 → 課程規劃表出得來 28 列、教室日誌選得到第 28 週、列印頁尾寫「共 28 週」。

做完你應該看到

  • 進到第 1 週，全部學生預設是「出席」。
  • 把 2 個人改成請假 → 材料費份數與出席率兩個數字同步跟著變。
  • 請假的人仍然算在出席率的分母裡（出席率＝出席人數 ÷ 總報名人數）。
  • 只點一半的人 → 出現「還有 N 位未點名，這週的數字先不算數」。

常見的錯：AI 把請假的人從分母扣掉，出席率就會虛高；或是材料費份數寫死加 2 位老師，不管基本資料實際填了幾位。

第 5 關　對外產出有提示詞

這關要達成什麼

做「學生回饋單」與「經費核銷」，讓總覽頁的七個百分比全部長出來。

可複製提示詞

延續上一步做好的同一個檔案，不要重做、不要換檔名、不要新開一個檔，只在原檔上繼續加功能。已經做好的功能不可以弄壞。

這一關做「學生回饋單」與「經費核銷」兩個分頁，這兩頁的數字要能直接抄進官方成果報告書。

【學生回饋單】
(1) 「回收份數（實際收回的份數）」輸入框，旁邊自動顯示「應收 N 份（名單人數自動帶入）｜回收 x 份／應收 N 份」。
(2) 四道題目的統計表，每題四個選項各填人數，最右邊自動算「達成率」＝（很同意＋同意）÷ 回收份數。
    四道題目文字固定用這四句，一題對一個官方百分比，不要改字：
    1. 參加社團以後，我更想知道科學的「為什麼」　（對應①學生對科學探索的興趣提升）
    2. 上課的時候，我會專心聽，也會跟大家一起討論　（對應②上課專心、能參與討論）
    3. 做實驗的時候，我會照安全規則做，可以自己完成，或老師稍微提醒一下就能完成　（對應③能自己完成實驗操作）
    4. 我可以跟別人說明我們的實驗在做什麼，或介紹我做出來的成果　（對應④能向別人說明實驗）

(3) 選項合計勾稽，三種狀態，不要一律報錯：
    ・某題四個選項合計 > 回收份數 → 紅字「合計 X ＞ 回收 Y，請檢查（是不是把人次當成人數了？）」，該題達成率顯示「—」。

(4) 一顆「列印空白回饋單（發給學生）」：印出 A4 紙本問卷，含班級／座號欄、四題選擇題（四個方框讓學生勾）、第 5 題開放題「這學期我最喜歡的一堂課是＿＿，因為＿＿」。
(5) 最下面一個多行文字框「第 5 題（開放作答）彙整」，給老師抄學生寫的內容，期末寫「伍、結論與建議」直接取材。

【經費核銷】
(1) 抬頭紅字，一字不要改：

(2) 登記列：類別下拉（材料費、鐘點費、導師費、餐費、教學演示費、指導出席費、交通費、住宿費，共八個科目）、認列日期、品項說明、金額、份數、對應週次（下拉含「整學期／未指定」與第 1～N 週）、登記按鈕、匯出 CSV。

    上方八個科目各一張累計金額卡。
(4) 「材料費對帳」表：逐週比對「出席＋實際授課教師人數」與該週登記的材料費份數，相符顯示 ✔、不符顯示差幾份。若有「整學期／未指定」的登記，多出一列把它們加總跟全期合計比對，此時各週改顯示「含在整學期登記（見下方全期合計）」。
    表格上方要寫明：核算公式（上課人數＋實際授課教師人數）× 主題 × 250 元；並註明「材料費、餐費、茶水費的發票／收據，需開立基金會統編：82339563 財團法人仰望教育基金會」。

【總覽頁的七個百分比】
在「總覽」做一個「效益達成情形（成果報告書・肆）」儀表板，七張大卡片：

⑤ 社團整體出席率（教室日誌自動算）
⑥ 課程延伸應用到正式自然課（老師自己填）
⑦ 老師覺得對專業有實質幫助（老師自己填）
每張卡顯示大數字百分比與來源說明；沒資料時顯示「—」。⑥⑦ 下面各給一個輸入框讓老師填。

【做完請自己驗收並回報】
1. 回饋單回收 15、某題填 8/8/0/0 → 紅字提醒，且該題達成率顯示「—」。
2. 同一題改成 7/0/0/0 → 灰字「尚未填完」但仍算得出百分比。
3. 核銷登記一筆「整學期／未指定」的材料費 → 對帳表多一列做全期比對。

做完你應該看到

  • 回饋單填了人數，四題的達成率自動算出來。
  • 某題四個選項合計超過回收份數 → 紅字提醒，達成率顯示「—」。
  • 核銷八個科目都選得到，畫面上看得到統編 82339563。

常見的錯：AI 把達成率算成（很同意＋同意）÷ 名單人數，而不是 ÷ 回收份數；或是合計對不上就整個報錯不給數字——要求它分成「超過／未填完／剛好」三種狀態處理。

第 6 關　交得出去有提示詞

這關要達成什麼

做列印、Word 成果報告書、檔案上傳、下載隨身版——期末真正要交出去的東西。

可複製提示詞

延續上一步做好的同一個檔案，不要重做、不要換檔名、不要新開一個檔，只在原檔上繼續加功能。已經做好的功能不可以弄壞。

【一、列印（用瀏覽器列印，不要用任何外部套件）】
做法：準備一個平常隱藏的 #printArea，按列印鈕時把要印的 HTML 塞進去再呼叫 window.print()；用 @media print 讓列印時只顯示 #printArea。每一張列印頁的頁首都要有：學校名、社團名、學年度。

2. 授課時數表（鐘點費核銷用，逐列實填時數、頁尾合計、下方留承辦人／主任／校長簽名欄）

5. 成果報告書素材頁（一張 A4：上半是壹的基本資料含兩位指導老師，下半是七個百分比，每個數字後面帶來源與分母，例如「③ 82%（回收 17 份：很同意 8＋同意 6）」「⑤ 91%（已點名 12 週）」；若有回饋單第 5 題彙整，一併印出當「伍」的素材）

【二、一鍵產生 Word 成果報告書】
做一顆按鈕「列印成果報告書（Word）」，按下去產生一個 Word 打得開的 .doc 檔，**不可以用任何外部套件**。
做法：組一份 MHT（multipart/related）文字。第一個部件是 base64 過的 HTML（Content-Location: report.htm），之後每一張上傳的圖片各一個部件（base64、Content-Location: img1.png 之類），HTML 裡用 <img src="img1.png"> 對應；最後整包做成 Blob（type: application/msword）下載，檔名例如「成果報告書_學校名_20260819.doc」。base64 要用 UTF-8 安全的作法（btoa(unescape(encodeURIComponent(str)))）。
報告內容照官方《115 學年度國中小科學社團扶助計畫 成果報告書》的架構：
・封面：115學年度財團法人仰望教育基金會／國中小科學社團扶助計畫 成果報告書／主辦單位（我的學校）／贊助單位：財團法人仰望教育基金會／中華民國　年　月　日
・壹、基本資料（表格：贊助單位、主辦單位、負責人／承辦人員、計畫名稱、計畫期程「自115年08月01日至116年07月31日止」、計畫對象、計畫方式、補助經費、開設班別、課程時間及週數）
・貳、課程規劃表（整張表）
・參、課程紀錄（一、課程／活動紀錄：把各週填的課程紀錄文字串起來，並內嵌該項上傳的照片；二、學生作品或成果發表）
・肆、效益達成情形（表格：學生面 ①～⑤、師資面 ⑥⑦，帶入實際百分比與回收份數）
・伍、結論與建議（帶入回饋單第 5 題彙整）
・陸、附件：一、學生名單（序號｜班級｜性別｜姓名）；二、學生出席表（每位學生 × 已點名週次，✓／✗／假）；三、學生回饋單統計；四、經費使用一覽（含合計與統編註記）；五以後：文件繳交追蹤裡每一項上傳的檔案（圖片直接內嵌，非圖片列出檔名清單）。
字體用標楷體優先，每一大節之間分頁。

【三、文件繳交追蹤（放在總覽頁）】
表格四欄：結案文件｜檔案上傳｜狀態｜備註／提示。共 12 列：課程規劃表（貳）、學生名單（附件一）、單元教案、社團課簽到表（附件二）、學生回饋單（附件三）、課程紀錄（參）、觀課紀錄表、專家聯絡單、專家教學演示紀錄表、教授訪視觀課指導紀錄表、校內核銷各類表格、成果報告書。
・「檔案上傳」欄：每一列都能上傳檔案，**用 IndexedDB 存**（資料庫名例如 yw-files-加上 STORE_KEY），每列最多 50 個。已上傳的列出檔名與大小，可以點檔名下載、也可以刪除，並顯示「共 N／50 個」。丟超過 50 個只收前 50 個並提示。

・「成果報告書」那一列，在名稱下方多一顆「列印成果報告書（Word）」按鈕。

常見的錯：AI 想裝 docx 套件（違反零外部資源），要堅持用 MHT 純文字組出 .doc。另一個常見錯是忘了告訴老師「上傳的檔案存在瀏覽器裡，不會跟著 .json 備份走」，老師換電腦就以為檔案不見了。

三、資料怎麼存（照這個做，不然老師會弄丟資料）
────────────────────────────────
1. 用瀏覽器的 localStorage 存全部表單資料，鍵值用一個固定字串（例如 yw-club-mgr-北昌）。
   任何欄位一改就自動存，並更新頂欄的「已自動存檔 時:分:秒」。
2. **同時**在 HTML 裡放一個內嵌資料節點：
   <script type="application/json" id="bootState">null</script>
   每次自動存檔時，把整包資料 JSON 也寫進這個節點的內容（記得把 < 換成 \u003c 避免壞掉）。
3. 開檔時的還原順序：
   先讀 localStorage；**這個位置沒有資料時**，才去讀 #bootState 的內容還原，並立刻存進 localStorage。
   → 已經在用的資料永遠優先，不會被舊快照蓋掉；按「清除全部資料」後重開也不可以還魂。
4. 為什麼要這樣：老師會把檔案存到隨身碟、帶去別台電腦。localStorage 不會跟著檔案走，
   內嵌節點會。這是這個系統能「帶著走」的關鍵，請務必實作。
5. 注意：不要用 DOM 元素屬性（例如 dataset）當「已初始化」的旗標，
   因為 Ctrl+S 存下來的快照會把屬性一起存走，重開後判斷會失準。請用 JavaScript 變數。
