要離線用：到「備份與設定」按 **「下載隨身版 HTML（含目前資料）」**——存出來的檔案雙擊即開、資料跟著檔案走（Ctrl+S 也行，但要選「網頁，完整」）。
⚠ 線上版和本機檔**不會互相自動同步**——認定一份當主要工作檔；搬資料用「下載隨身版」或備份匯出／匯入。

## 怎麼拿到、怎麼打開

1. 下載 [`index.html`](index.html)（通用版），或到 [`schools/`](schools/) 資料夾下載已預填校名的版本。
2. 存到自己電腦任何位置（桌面即可）。
3. **點兩下**，用瀏覽器（Edge / Chrome）打開，就能用了。

> 各校把自己的名單「貼上匯入」就能用——從 Excel 複製整批學生，貼進「學生名單」分頁的匯入框即可，支援「座號 班級 姓名」「班級 姓名」「姓名」三種格式。

## 三個核銷地雷（系統內建提醒）

1. 同一張請購單，2026 年 9–12 月和 2027 年 1–6 月要分開填。
2. 鐘點費認列「實際上課日期」，不是請購日期。
3. 材料費認列「發票上的日期」；份數要和教室日誌「出席學生數＋實際授課教師人數」相符（核算式：（上課人數＋實際授課教師人數）×主題×250 元；發票統編 82339563）。

## 資料安全

- 資料只存在**開啟檔案的那台電腦、那個瀏覽器**（localStorage），不會上傳到任何地方。
- 請養成習慣：每次上完課點「匯出備份」。**.json 備份裡有整班學生姓名——存學校配發的隨身碟或校內雲端，不要放個人雲端、不要用 LINE 或 email 傳。**「學生名單.csv」「出席總表.csv」同樣有整班姓名，要給 AI 看之前先把姓名欄換成座號。
- 換電腦：新電腦打開同一個 HTML → 備份與設定 → 匯入備份。
- 電腦要送修、要還、要借人之前：**先按「匯出備份」把 .json 存好，再按「清除全部資料」**。光把 HTML 檔刪掉沒用——名單存在瀏覽器裡，不會跟著檔案走。
- **身分證字號、戶籍住址、匯款帳號——這三樣不貼進任何 AI，也不放雲端，只在學校的紙本表上寫。AI 幫你算的是時數、份數、金額，不碰身分資料。**
